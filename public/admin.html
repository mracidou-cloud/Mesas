Sign in

Enter the admin password (it’s in config.json).

1. Event details

Change the name, how many tables there are and how many guests fit at each one. The screen redraws itself when you save.

If left empty, an animation of a dancing couple is shown.

2. Guest list

Edit here, or paste two columns straight from Excel / Google Sheets: name and table.

#NameTableStatus

💾 Save permanently

On Render’s free plan, changes made here are lost when the service restarts or “goes to sleep”. When you finish setting things up, download these two files and upload them to your GitHub repository (replacing the old ones).

3. During the event

If someone picked the wrong name, remove it in the table above (“undo check-in” button). Before starting a new event, reset all check-ins.

4. Layout — move the tables and the QR ✥

Drag each table and the QR code to where you want them, then press Save layout. The screen updates right away. Tables in red are overlapping something.

Preview ↗

5. Wishes wall ✍️

After checking in, guests can type (with emojis) or draw a short message. It appears on the big screen in a column on the right; each wish moves to the middle, stays large for about 2 seconds, then the next one comes up.
